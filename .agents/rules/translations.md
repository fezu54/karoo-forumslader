# Translation Guidelines

Whenever you add or modify a user-facing string resource (e.g., in `res/values/strings.xml`), you MUST ALWAYS provide the corresponding German translation in the German strings file (e.g., `res/values-de/strings.xml`). 

Never leave strings untranslated. If you are unsure of the exact German translation, provide your best accurate translation.
