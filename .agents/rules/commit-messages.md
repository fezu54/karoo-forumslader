# Commit Message Guidelines

Every commit MUST include both:

1. A Conventional Commits subject line (`feat(scope): ...`, `fix(scope): ...`, `docs: ...`, `ci: ...`, `style: ...`, etc.).
2. A blank line followed by a concise, descriptive commit body explaining **why** the change was made and **what** key changes were introduced (e.g., affected components, behavior changes, or edge cases).

Never create subject-only one-line commits.
